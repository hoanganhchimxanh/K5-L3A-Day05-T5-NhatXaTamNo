# THƯ MỤC PROTOTYPE — NHÓM NHATXATAMNO (TRACK T5 MOMO)

## 1. Cách chạy Prototype
* Mở trực tiếp file `index.html` trong bất kỳ trình duyệt web nào (Chrome, Edge, Safari, Firefox). Không cần cài đặt server, không cần API key.

## 2. Các thành phần chính trên giao diện (Đánh số phục vụ chấm Rubric R5)
1. **[Vùng 1 - Header]:** Nhãn định danh AI minh bạch: `AI Assistant · HAX G2` (tuân thủ Điều 11 Luật AI 134/2025/QH15).
2. **[Vùng 2 - Banner Rủi ro]:** Giải thích lý do và bằng chứng chặn tiền (nguyên tắc PAIR Explainability + Trust).
3. **[Vùng 3 - Đếm ngược 30 phút]:** Thể hiện tool `giu_giao_dich` hoạt động ở mức **Tự làm (Full-auto)**.
4. **[Vùng 4 - Nút Quét FaceID]:** Thể hiện tool `yeu_cau_xac_minh` (Tự làm) để người dùng tự xác thực danh tính.
5. **[Vùng 5 - Nút Chuyển Tư vấn viên P0]:** Thể hiện tool `chuyen_tu_van_vien` (Tự làm) — đường lui an toàn (Safe Fallback).
6. **[Vùng 6 - Nút Nhả tiền / Hủy tiền an toàn]:** Thể hiện tool `nha_giao_dich` ở mức **Cần người duyệt (User Confirm / Staff Approval)**.
7. **[Vùng 7 - Bảng điều khiển giả lập (Control Panel)]:** Cho phép Giảng viên / TA chuyển đổi 4 ca thử nghiệm tức thì chỉ bằng 1 click.
